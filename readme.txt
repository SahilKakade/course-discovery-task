# Course Discovery System

A custom course discovery system built for Oxford International using WordPress and Advanced Custom Fields (ACF).

## Overview

This project provides a structured course discovery experience for managing and presenting course-related information through a custom WordPress implementation.

The system uses custom post types, ACF fields and custom theme functionality to organize courses, instructors and providers while providing a flexible frontend experience.

## Features

- Custom course discovery interface
- Custom WordPress theme implementation
- Custom post types for courses, instructors and providers
- Advanced Custom Fields (ACF) integration
- Structured course information management
- Dynamic content rendering
- Custom responsive UI
- Custom CSS styling
- WordPress-based content management

## Technical Implementation

The project uses WordPress custom post types and ACF fields to structure and manage course-related data.

Custom PHP functionality is used to query and render the required content within the WordPress theme.

The frontend uses HTML and CSS with custom theme templates to create the course discovery experience.

## Tech Stack

- WordPress
- PHP
- Advanced Custom Fields (ACF)
- HTML
- CSS
- JavaScript

## Getting Started

### Theme Setup

Clone or copy the theme into your WordPress installation:

```text
wp-content/themes/
Install Required Plugin

Install and activate:

Advanced Custom Fields (ACF)
Import ACF Configuration

Import the provided ACF configuration through:

WordPress Admin → ACF → Tools → Import Field Groups
Activate the Theme

From the WordPress dashboard:

Appearance → Themes

Activate the course discovery theme.

Custom Content Structure

The project uses custom post types for:

Courses
Instructors
Providers
